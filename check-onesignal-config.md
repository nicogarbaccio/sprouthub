# Check OneSignal Dashboard Configuration

The Player ID is still undefined even though:
- ✅ Permission: granted
- ✅ Service worker: registered
- ✅ Notifications enabled in browser
- ❌ Player ID: undefined (subscription not created)

This usually means OneSignal Web Push platform is not fully configured.

## What to Check in OneSignal Dashboard

1. Go to: https://dashboard.onesignal.com/
2. Select your **SproutHub** app
3. Go to **Settings** → **Platforms** (left sidebar)
4. Find **Google Chrome / Firefox** (Web Push)

### Required Configuration:

**Site URL**: Must be set to `https://localhost:8080` (or your production URL)

Without this, OneSignal won't generate push subscriptions.

### How to Configure:

1. Click **Configure** on the Web Push platform
2. In "Site URL", enter: `http://localhost:8080` (for local dev)
3. Click **Save**

### VAPID Key:

Should be auto-generated by OneSignal. If you see "Generate VAPID Keys", click it.

---

## After Configuration

Once you've set the Site URL:

1. Refresh your browser page
2. Check Player ID again:
   ```javascript
   await OneSignal.User.PushSubscription.id
   ```

This should finally generate a subscription!
